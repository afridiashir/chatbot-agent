# Notification sounds

Drop an audio file here and the agent inbox plays it instead of its built-in
tone. Nothing else to change:

| File            | Plays when                    |
| --------------- | ----------------------------- |
| `message.mp3`   | a visitor sends a message     |
| `new-chat.mp3`  | a new conversation is assigned |

`.mp3` keeps every browser happy; keep them under a second. With no file here,
the inbox synthesises a short bell instead.

Use a sound you have the right to use — your own recording, or one licensed for
commercial use. WhatsApp's own tones are Meta's property and must not be copied
into this project.
